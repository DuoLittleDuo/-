# 欢迎页照片投放说明

把照片按下面的文件名放进本目录即可，页面会自动读取。**所有文件都是可选的**：没有放的文件会显示陶土色系 + emoji 的排版兜底，不会出现破图，也不会跳版。

| 文件名 | 建议比例 | 建议内容 |
|---|---|---|
| `hero-cat.jpg` | 4:5 竖图，≥1200px 宽 | 猫咪在陶碗前低头进食，或与陶器同框 |
| `hero-dog.jpg` | 3:4 竖图，≥900px 宽 | 狗狗守着它的陶制食盆 |
| `season-spring-cat.jpg` | 4:3 横图，≥1000px 宽 | 春 · 晨食：清晨猫咪吃饭 |
| `season-summer-dog.jpg` | 4:3 横图，≥1000px 宽 | 夏 · 饮水：狗狗在陶碗边喝水 |
| `season-autumn-cat.jpg` | 4:3 横图，≥1000px 宽 | 秋冬 · 守候：猫咪趴在碗边等待 |
| `craft-hands.jpg` | 3:2 横图，≥1200px 宽 | 匠人拉坯/刻花/窑火等陶艺场景 |

建议使用 JPG 或 WebP，单张控制在 500KB 以内，保证演示时加载流畅。文件名区分大小写，不要改名。
